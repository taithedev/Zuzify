# Content and links

Add or update project entries in `packages/catalog/src/products.ts`.

Use `repoUrl` only for known public repositories, and `websiteUrl` only for confirmed live websites.
Provide a stable unique `slug`, title, category, short tagline, description, status, and icon.

The directory is not a live uptime dashboard; product statuses are editable content.
Contact can be configured in the shell using a public channel instead of exposing private email.
